# Market Expense Manager

A minimalist market expense management website built with HTML, CSS, and JavaScript, featuring a sleek calculator-inspired dark theme.

## Features

- **Minimalist dark theme**: Clean, high-contrast design for easy readability
- **Store name tracking**: Enter store names once, and they'll be available in a dropdown for future use
- **Budget management**: Set and track your budget with real-time updates
- **Expense tracking**: Add, view, and delete your expenses
- **Responsive design**: Works on desktop and mobile devices
- **Local storage**: All your data is saved in your browser's local storage

## How to Use

1. **Set a Budget** (Optional)
   - Enter an amount in the budget field
   - Click "Set Budget" to update your total budget

2. **Add Expenses**
   - Enter the store name (optional), price (required), and quantity (defaults to 1)
   - Add item name and category if desired
   - Click "Add Expense" to save

3. **View Expenses**
   - See all your expenses in the table at the bottom
   - Delete any expense by clicking the ❌ button

## Running the Website

Simply open the `index.html` file in any modern web browser. No server or installation required!

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Local Storage API for data persistence
